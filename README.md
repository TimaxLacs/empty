# 2-е звено — комплектация снаряжения

Сводка по одежде, экипировке и снаряжению личного состава. Собрана из сообщений каждого человека и сверена с обязательным перечнем.

## Как смотреть

- **[Текстовая сводка](equipment/SVODKA.txt)** — полный единый список по всем, удобно копировать в чат.
- **[Текстовый отчёт](equipment/REPORT.md)** — тот же состав в Markdown.
- **[Интерактивный отчёт](equipment/index.html)** — сводка, матрица и карточки.

Процент считается по 51 обязательной позиции: одежда, зима, базовая экипировка и снаряжение. «Едет» в текущую готовность не входит. Индивидуальные вещи по специальности и пункты «по желанию» в процент не входят.

Привод, магазины, лоадер, шомпол, зарядное, шары и аккумулятор в базовый список не входят, но вынесены в блок «Прочее», потому что их тоже проверяют.

## Как обновлять

1. Править статусы в `equipment/data.json`.
2. Собрать страницу и Markdown:

```bash
python3 equipment/build.py
python3 equipment/render_markdown.py
python3 -m unittest equipment/test_inventory.py
```

Знаки в данных: `+` есть, `-` нет, `>` едет, `~` частично, `!` есть/взять, `x` не требуется, `?` не сказано.
